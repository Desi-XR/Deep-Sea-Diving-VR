# 🌊 Deep Sea Diving VR

A 3D immersive **Deep Sea Diving experience** built using **AR/VR technologies** as part of the *DES643: Design for AR and VR* course at **IIT Kanpur**.

This project aims to simulate a realistic underwater environment, allowing users to explore the deep ocean through virtual reality with interactive elements and atmospheric effects.

---

## 🚀 Features

* 🌊 Realistic ocean simulation using Crest Water System
* 🤿 Immersive underwater experience with depth-based visuals
* 🫧 Environmental effects like fog, lighting, and water attenuation
* 🎮 Designed for VR interaction and exploration
* 🐠 Scope for marine life and interactive objects

---

## 🛠️ Tech Stack

* **Engine:** Unity
* **Water System:** [Crest Ocean System](https://github.com/wave-harmonic/crest)
* **Platform:** VR (XR Toolkit)
* **Language:** C#
